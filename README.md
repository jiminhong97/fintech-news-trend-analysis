# Fintech News Trend Analysis

2016~2025년 국내 핀테크 뉴스 데이터를 대상으로 기술·서비스 키워드의 변화와 동시 등장 관계를 분석한 텍스트 분석 프로젝트입니다.

## 프로젝트 소개

BIGKinds에서 수집한 20,563건의 뉴스 기사를 대상으로 중복 제거, 규칙 기반 관련 기사 필터링, 텍스트 정제, 형태소 분석, 불용어 제거, 복합어 통합을 수행하였습니다. 이후 연도별 상위 키워드, 키워드 범주 변화, 핵심 기술별 기사 수, 기술-서비스 동시 등장 관계, n-gram 및 핵심 표현 추세를 분석하였습니다.

본 저장소의 코드는 수업 당시 작성한 Jupyter Notebook의 HTML 저장본을 바탕으로, 최종 분석 흐름이 한 번에 실행되도록 정리한 버전입니다. 분석에 사용한 키워드·불용어·복합어 사전과 주요 처리 기준은 원 프로젝트의 최종 설정을 유지하였습니다.

## 데이터

- 데이터 출처: BIGKinds
- 분석 기간: 2016~2025
- 최초 기사 수: 20,563건
- 중복 제거 후: 19,045건
- 1차 관련성 필터 후: 11,947건
- 2차 관련성 필터 후: 11,924건
- 주요 컬럼: 일자, 언론사, 제목, 키워드, 본문, URL 등

원본 뉴스 데이터는 저장소에 포함하지 않았습니다.

## 분석 흐름

1. **뉴스 데이터 병합 및 중복 제거**  
   기간별 CSV 3개를 병합하고 URL 및 제목·본문 기준으로 중복 기사를 제거합니다.

2. **규칙 기반 관련 기사 필터링**  
   핀테크 핵심 키워드, 금융 문맥 키워드, 비관련 산업 키워드를 이용하여 분석 대상 기사를 선별합니다.

3. **텍스트 정제 및 형태소 분석**  
   특수문자와 불필요한 표현을 제거한 뒤 KoNLPy의 Okt를 이용하여 명사와 영문 중심으로 토큰화합니다.

4. **불용어 제거 및 복합어 통합**  
   뉴스 기사에서 반복되는 일반 표현을 제거하고 블록체인, 마이데이터, 오픈뱅킹, 카카오페이 등 분리된 표현을 하나의 토큰으로 통합합니다.

5. **연도별 키워드 및 범주 분석**  
   핵심기술, 기반기술/패러다임, 서비스, 기업/플레이어, 정책/규제, 금융인프라 범주로 키워드를 분류합니다.

6. **기술-서비스 동시 등장 분석**  
   AI, 블록체인, 마이데이터, 오픈뱅킹, 토큰증권 등 핵심 기술이 어떤 금융 서비스 문맥과 함께 등장하는지 분석합니다.

7. **n-gram 및 핵심 표현 추세 분석**  
   bigram·trigram을 생성하고 생성형 AI, 금융 AI, 디지털 자산, 토큰 증권 등 주요 표현의 연도별 기사 수와 정규화 빈도를 계산합니다.

## 분석 결과 예시

- 2019년에는 블록체인 관련 기사가 크게 증가했으며, 오픈뱅킹과 암호화폐도 주요 키워드로 나타났습니다.
- 2020~2022년에는 마이데이터와 가상자산 관련 키워드가 주요 흐름으로 나타났습니다.
- 2023년 이후에는 AI, 토큰증권(STO) 등의 비중이 확대되었고, 2025년에는 AI 관련 기사 수가 뚜렷하게 증가했습니다.
- 기술 키워드를 서비스 키워드와 연결하여 투자, 결제, 증권, 대출, 자산관리 등 어떤 서비스 맥락에서 기술이 언급되는지도 확인하였습니다.

위 결과는 본 프로젝트의 규칙 기반 전처리와 키워드 사전을 기준으로 산출한 기술통계 결과입니다.

## 실행 방법

1. 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

2. BIGKinds에서 내려받은 기간별 CSV를 `data/` 폴더에 배치합니다.

```text
data/
├── 핀테크 뉴스 (2016-2018).csv
├── 핀테크 뉴스 (2019-2022).csv
└── 핀테크 뉴스 (2023-2025).csv
```

3. 저장소 루트에서 실행합니다.

```bash
python src/fintech_news_analysis.py
```

분석 결과 CSV는 `results/` 폴더에 저장됩니다.
