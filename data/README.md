# Data

본 프로젝트는 BIGKinds에서 수집한 2016~2025년 핀테크 관련 뉴스 데이터를 사용합니다.

원본 뉴스 데이터는 저장소에 포함하지 않습니다. 코드를 실행하려면 다음 파일을 이 폴더에 배치합니다.

```text
핀테크 뉴스 (2016-2018).csv
핀테크 뉴스 (2019-2022).csv
핀테크 뉴스 (2023-2025).csv
```

주요 사용 컬럼은 다음과 같습니다.

- 뉴스 식별자
- 일자
- 언론사
- 기고자
- 제목
- 키워드
- 특성추출(가중치순 상위 50개)
- 본문
- URL
- 분석제외 여부
